A snapshot of the **old** brianmcmichael.com site, kept for reference. Not part
of the live site; nothing here is linked from `index.html`.

- **Archived:** 2026-08-17
- **Source:** working tree of `git@github.com:brianmcmichael/brianmcmichael.com.git`
  (the pre-redesign site), copied verbatim minus its `.git` directory.
- `index.html` here is the old minimalist page.
- `20210420brianmcmichael.zip` is a full 2021 backup that also contains the
  earlier Windows-3.1 "Program Manager" desktop design (draggable windows,
  About / Contact / Resume / Projects), which is not present in the loose files.
- `img/`, `files/`, `favicon.ico`, `keybase.txt`, `sitemap.xml` are the old
  site's assets as they last existed.

The old repository's granular commit history is not preserved here — only this
content snapshot.
